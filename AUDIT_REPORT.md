# Отчёт о проверке проекта

В комплект входят модули сбора RSS, работы с Telegram, ИИ-обработки, публикации, планировщика, административного интерфейса и тесты.

## Области проверки

- Настройки ИИ на уровне каналов и режим `ОРИГИНАЛ БЕЗ ИИ`.
- Получение RSS/Atom и доступных Telegram-источников.
- Очередь, модерация, расписание и публикация.
- Сетевые проверки URL, секреты и настройки веб-панели.
- Длинные сообщения, восстановление состояния и регрессионные тесты.

## Ограничения

Unit/regression-тесты не подтверждают доступность всех сторонних сайтов, работу каждого внешнего API или корректность любой конфигурации production. Требуются интеграционные проверки на собственном сервере.

## Перед выпуском

Пройдите `RELEASE_CHECKLIST.md`, проверьте каждый тип источника, каждый ИИ-провайдер, оригинальный режим, расписание, резервное восстановление и права доступа.
