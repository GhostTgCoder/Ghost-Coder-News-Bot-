# Ghost Coder News Bot

**Автоматизация сбора, подготовки и публикации новостей в Telegram.**

Ghost Coder News Bot собирает материалы из RSS/Atom и доступных Telegram-источников, помогает обрабатывать тексты с помощью ИИ, управляет очередью публикаций и поддерживает модерацию и расписание.

**[🛒 КУПИТЬ GHOST CODER NEWS BOT НА KWORK](https://kwork.ru/script-programming/55120212/telegram-bot-kotoriy-sam-sobiraet-i-publikuet-novosti)**

**Версия:** `0.9.0-rc1` · **Статус:** Release Candidate — перед рабочим запуском необходимы интеграционные проверки.

## Возможности

- Несколько Telegram-каналов с отдельными настройками.
- Сбор материалов из RSS/Atom.
- Получение публикаций из доступных Telegram-источников через настроенную MTProto-сессию.
- Отдельный ИИ-провайдер и инструкции для каждого канала.
- Режим **«ОРИГИНАЛ БЕЗ ИИ»**, использующий сохранённые исходные заголовок и текст.
- Очередь публикаций: просмотр, редактирование, одобрение, отклонение и ручная публикация.
- Модерация перед публикацией.
- Расписание, интервалы и тихие часы.
- Фильтры по типу контента: текст, фото, видео и их сочетания.
- Теги и футер для оформления публикаций.
- Защита от дублей по источнику и содержимому.
- Доступные показатели публикаций и веб-панель администратора.
- Ограниченные очереди, проверки URL, обработка длинных сообщений и регрессионные тесты.

## Быстрый старт

1. Подготовьте Linux-сервер и Python.
2. Создайте бота через BotFather и получите `BOT_TOKEN`.
3. Установите зависимости из `requirements.txt`.
4. Скопируйте `.env.example` в `.env` и заполните обязательные параметры.
5. Запустите `python main.py`.
6. Добавьте бота в тестовый канал с правом публикации.
7. Подключите источники, настройте ИИ или выберите **«ОРИГИНАЛ БЕЗ ИИ»**.
8. Проверьте несколько публикаций вручную, затем включайте расписание.

Подробная инструкция: **[Установка](docs/INSTALLATION.md)**.

## ИИ отдельно для каждого канала

Добавьте ИИ-провайдера через интерфейс бота, затем назначьте его нужному каналу. Разные каналы могут использовать разные провайдеры и инструкции. Выбор **«ОРИГИНАЛ БЕЗ ИИ»** отключает ИИ-обработку для соответствующего канала; теги и футер при этом могут применяться отдельно.

## Для кого

Для владельцев новостных и тематических каналов, редакций и администраторов, которые хотят автоматизировать рутинные действия и управлять публикациями из нескольких источников.

## Важные ограничения

Бот не гарантирует доступность любого сайта или канала. Некоторые RSS-ленты содержат только анонс; сайты могут блокировать запросы или требовать JavaScript. ИИ может ошибаться. Убедитесь, что у вас есть право повторно публиковать выбранные материалы. Версия `0.9.0-rc1` — релиз-кандидат: тестируйте её на отдельном канале до рабочего использования.
