# Настройка Ghost Coder News Bot

Настройки окружения задаются в `.env`. Используйте `.env.example` и сверяйте названия переменных с текущей версией проекта.

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_IDS` | ID администраторов |
| `DATABASE_URL` | Подключение к базе данных; шаблон использует SQLite |
| `GROQ_API_KEY` | Ключ Groq, если провайдер используется |
| `AI_PROVIDER_ENCRYPTION_KEY` | Ключ Fernet для шифрования ключей провайдеров, добавленных через интерфейс |
| `TELEGRAM_API_ID` | API ID для MTProto |
| `TELEGRAM_API_HASH` | API Hash для MTProto |
| `TELEGRAM_SESSION` | Имя/путь пользовательской сессии |
| `POST_RETENTION_DAYS` | Срок хранения метаданных публикаций |
| `WEB_ADMIN_HOST` | Адрес привязки веб-панели |
| `WEB_ADMIN_PORT` | Порт веб-панели |
| `WEB_ADMIN_TOKEN` | Секрет доступа к веб-панели |
| `WEB_ADMIN_URL` | Публичный HTTPS-адрес панели, если используется |

## Telegram

Получите токен у BotFather. Ограничьте список администраторов. Если токен утёк, отзовите его и создайте новый.

## Ключи ИИ

Провайдер добавляется через интерфейс и назначается нужному каналу. Проверяйте тип провайдера, модель, базовый URL и ключ API. Учитывайте лимиты и тарифы поставщика.

Для генерации ключа шифрования:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Сохраните ключ отдельно: при его потере зашифрованные значения могут стать недоступны.

## Telegram MTProto

API ID и API Hash получают на https://my.telegram.org. Файл сессии является секретом, защищайте его правами файловой системы и не коммитьте в Git.

## База данных

Шаблон использует `DATABASE_URL=sqlite:///bot.db`. Уточните фактический путь базы в вашей установке. Настройте защищённые резервные копии и периодически проверяйте восстановление.

## Веб-панель

Задайте уникальный `WEB_ADMIN_TOKEN`. Предпочтительна привязка к localhost и публикация через HTTPS reverse proxy при необходимости. Не открывайте административную панель в интернет без защиты доступа.

## Настройки каждого канала

Проверьте источники, ИИ-провайдера или режим «ОРИГИНАЛ БЕЗ ИИ», теги, футер, фильтры содержимого, модерацию, расписание и права бота в целевом канале.
